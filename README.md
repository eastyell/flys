# 飞打机游戏

一款基于 HTML5 Canvas 的太空飞行射击游戏,纯前端实现,无需后端,开箱即玩。

## 如何运行

直接用浏览器打开 `index.html` 即可开始游戏。

## 操作说明

| 操作 | 按键 |
| --- | --- |
| 移动战机 | `W A S D` 或 `↑ ↓ ← →` 方向键 |
| 射击 | `空格键` |
| 背景音乐开关 | 顶栏 `♪ 开/关` 按钮 |

## 核心功能

### 战斗系统
- **玩家战机**:双管齐射能量光弹,带尾焰动画、座舱高光、机翼武器挂载等精细绘制
- **四种敌机类型**,根据分数递进解锁:
  - 侦察机(scout):小快低伤,蛇形俯冲,10 分起出现
  - 战斗机(fighter):中等,会射击,50 分解锁,25 分/只
  - 轰炸机(bomber):大慢高伤,UFO 造型带能量场和机械触手,200 分解锁,50 分/只
  - 精英机(elite):高威胁,红黑能量体带尖刺脉冲核心,500 分解锁,75 分/只
- **多变伤害**:不同敌机造成 1~3 点伤害,撞击和敌方子弹均会扣血
- **血量条**:敌机受伤后显示血量条,颜色随血量变化(绿→橙→红)
- **难度递增**:分数每过 100 分,敌机刷新间隔缩短

### 道具系统
- **医疗包**(70% 概率):拾取 +1 生命
- **护盾**(30% 概率):拾取后短暂无敌(3 秒)
- 随机刷新,向下飘落

### 视觉效果
- 星空滚动背景
- 爆炸粒子系统(命中小爆炸 / 击毁大爆炸)
- 敌机细节动画:机翼振动、引擎脉冲、能量场、眨眼、旋转触手等
- 玩家战机无敌闪烁

### 音效系统(Web Audio API 实时合成,无需音频文件)
- **射击音效**:方波合成短促"piu"声
- **爆炸音效**:白噪音 + 低频隆隆声经低通滤波,大型敌机用更响亮的版本
- **背景音乐**:三角波主旋律 + 锯齿波低音伴奏循环播放,可随时开关

### 排行榜系统
- 本地存储 TOP 10 最高分(`localStorage` 持久化,关闭浏览器不丢失)
- 游戏结束后输入名字保存,回车快捷提交
- 仅当分数能进榜时才显示保存区域
- 新入榜条目金色高亮动画,前三名金银铜配色

## 文件结构

```
flys/
├── index.html      # 页面结构
├── style.css       # 样式(战机、UI、排行榜、动画)
├── game.js         # 游戏逻辑(渲染、碰撞、音效、排行榜)
└── README.md       # 项目说明
```

## 技术栈

- **HTML5 Canvas**:2D 渲染
- **原生 JavaScript**:无任何框架依赖
- **Web Audio API**:音效与背景音乐实时合成
- **localStorage**:排行榜数据持久化

## 浏览器兼容性

支持现代浏览器(Chrome、Firefox、Edge、Safari),需启用 JavaScript 和 localStorage。
